## Context
`ctrl+shift+pageup` / `ctrl+shift+pagedown` are valid shortcut strings (keys.rs + chord_from_event). Capture mode often fails because the host terminal steals those chords for scrollback.

## Acceptance
- README notes: use `e` and type the chord string when capture fails
- Optional: status hint in CaptureChord mode if Esc/cancel after no event
