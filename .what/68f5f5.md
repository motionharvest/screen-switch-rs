## Context
Aaron wants a TUI control that opens `%LOCALAPPDATA%\ScreenSwitchRs\config.json` in `micro`.

## Why
Chord capture cannot always receive terminal-intercepted keys (e.g. Ctrl+Shift+PageUp/Down). Typing via `e` works, but editing the JSON in a real editor is nicer for multi-monitor setups and exotic chords.

## Acceptance
- Visible affordance in Normal mode (key and/or clickable header control), e.g. `o` / "open config"
- Suspend TUI (leave alt screen, disable raw/mouse), spawn `micro <config_path>`, wait for exit
- On return: restore TUI, reload config from disk, refresh status
- If `micro` missing: clear status error (optionally fall back to `$EDITOR` / `notepad` — confirm with Aaron)
- Help/status strings updated

## Notes
- Config path: `config::default_path()`
- Watcher already hot-reloads ~2s; TUI should still reload immediately on return
